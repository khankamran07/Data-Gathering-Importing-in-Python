# Data Gathering & Importing in Python
This section covers the fundamentals of **data gathering and data importing**, which is an important first step in the Data Analysis process. Before analyzing data, we need to collect data from different sources and load it into Python for further processing and analysis.

### Topics Covered

1. **Data Analysis Process**
   Understanding the different stages of data analysis, from collecting and cleaning data to analyzing and presenting meaningful insights.

2. **Importing Data from CSV Files**
   Learning how to read and work with CSV (Comma-Separated Values) files using Pandas.

3. **Importing Data from Excel Files**
   Learning how to load data from Excel `.xlsx` files into Python for analysis.

4. **Importing Data from JSON**
   Understanding how to import and work with JSON (JavaScript Object Notation) data, which is commonly used for APIs and web-based data.

5. **Importing Data from SQL**
   Learning how to connect to SQL databases and retrieve data using Python and Pandas.

6. **Importing Data from TXT Files**
   Understanding how to read and process data stored in plain text `.txt` files.

### Goal

The main goal of this section is to understand how to **collect and import data from multiple sources into Python**, preparing it for the next stages of the Data Analysis workflow such as **data cleaning, exploration, visualization, and deriving insights**.
